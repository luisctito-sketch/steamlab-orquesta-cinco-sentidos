STEAMLab — La orquesta de los cinco sentidos

Nombre de repositorio: steamlab-orquesta-cinco-sentidos
Dirección prevista: https://luisctito-sketch.github.io/steamlab-orquesta-cinco-sentidos/

Sube a la RAÍZ de tu repositorio GitHub los seis archivos del ZIP: index.html, roja.png, azul.png, verde.png, amarilla.png y README.txt. En Settings > Pages selecciona Deploy from a branch, main y / (root).

Funcionamiento: Empezar inicia el cambio automático aleatorio cada tres segundos, sin repetir la tarjeta anterior; Detener congela la carta visible. Pantalla completa amplía la vista. No requiere Internet después de cargar el sitio ni dependencias externas.
